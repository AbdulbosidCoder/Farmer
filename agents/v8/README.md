# Сюда положите ваш код v8

Файл должен называться `agents/v8/main.py` (как для сабмита на Kaggle: функция `agent(obs)` —
последняя функция в файле).

Как он используется:

1. **Как соперник/бенчмарк.** Если `agents/v8/main.py` существует, `trainer/evolve.py`
   автоматически добавляет его в пул соперников каждого поколения (`--games-v8`, по умолчанию 2 игры
   на кандидата), а в `avlod/avlod_NNN/stats.json` пишется `v8_winrate`.
2. **Как основа для эволюции.** Если в v8 есть словарь-литерал `PARAMS = {...}` с числами,
   можно эволюционировать сами параметры v8:

   ```bash
   python -m trainer.evolve --agent agents/v8/main.py --fresh
   ```

   Границы поиска берутся из `PARAM_BOUNDS = {"имя": (min, max), ...}` если он есть в файле,
   иначе автоматически `[0, 2*значение]`. Удобнее всего обернуть параметры маркерами
   `# === PARAMS BEGIN ===` / `# === PARAMS END ===`.
3. **Тесты.** `pytest tests/` проверяет v8 на соответствие правилам соревнования и
   (`test_v8_is_beaten_by_best`) что лучшее поколение из `avlod/best` обыгрывает v8.
